# Customer Churn Analysis

## Project Objective
Analyze customer churn behavior and identify factors affecting customer retention using Python data analysis and visualization techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Month-to-month customers churn more.
- Customers with high monthly charges show higher churn.
- Customers without tech support and online security churn more.
- Lower tenure customers are more likely to churn.
